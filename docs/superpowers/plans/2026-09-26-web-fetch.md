# Link Okuma (WebFetch) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** usta'ya verilen bir link'i model açıp okuyabilsin: CLI backend'de `WebFetch` izni, API backend'de `web_fetch` server aracı.

**Architecture:** İki küçük araç-listesi değişikliği. CLI: `--allowedTools` değeri bir sabite çıkar ve `WebFetch` eklenir. API: istek araç listesine `web_fetch_20260209` eklenir, web ipucu `web_fetch_tool_result`'ı da tanır.

**Tech Stack:** Rust, `claude` CLI (`-p`), Anthropic Messages API (reqwest, ham JSON).

**Spec:** `docs/superpowers/specs/2026-09-26-web-fetch-design.md` — önce oku.

**Ön-koşul notu:** `main`, v0.31.2, temiz ağaç. Bekleyen `2026-09-04-rustls-portability` planı hâlâ v0.31.2 hedefliyor; bu plan v0.31.3'ü alır, rustls bir sonrakini. Kod olarak çakışmazlar.

## Global Constraints

- `Bash`, `Edit`, `Write` izinli araçlara GİRMEZ (Hard Rule 1: Usta dosyaya dokunmaz).
- CLI araç değeri tam olarak `"WebSearch,WebFetch"` (virgüllü tek argüman).
- API aracı tam olarak `type: "web_fetch_20260209"`, `name: "web_fetch"`; beta başlığı YOK.
- Dokunulmayanlar: backend seçimi (`select`), `--setting-sources ""`, modeller, brain/system prompt dosyaları, TUI.
- `cargo fmt` sadece düzenlenen dosyada: `cargo fmt -- <dosya>`.
- Bilinen ortam hatası, düzeltilmez: `materials::tests::convert_pdfs_missing_tool_reports_notice_and_no_txt`.
- Push yok, merge yok.

```rust
/// Did the response use the web (search or page fetch)? (for the UI hint)
pub fn used_web_search(content: &[Value]) -> bool {
    content.iter().any(|b| {
        matches!(
            b.get("type").and_then(Value::as_str),
            Some("web_search_tool_result")
                | Some("web_fetch_tool_result")
                | Some("server_tool_use")
        )
    })
}
```
